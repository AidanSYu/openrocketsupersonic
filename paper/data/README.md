# Publication / analytical validation data

Generated by `PublicationAnalyticalDataExportTest` in the `core` module.

## Regenerate

```bash
./gradlew :core:test --tests info.openrocket.core.aerodynamics.PublicationAnalyticalDataExportTest
```

## Use this folder in three layers

1. Source-anchored building blocks: atmosphere, shocks, expansions, cone flow, and Cp,max.
2. External component / vehicle benchmarks: NACA nose-shape data, AGARD-B, and future Cn(alpha) sets.
3. Reviewer defense boundary: keep manuscript claims inside what has layers (1) and (2); treat flight replay and tuned dynamic-stability terms as supporting evidence only.

## Highest-impact publication gates

1. Close exact/tabulated validation for every analytical building block.
2. Close at least one exact-geometry external Cd(M) benchmark with documented uncertainty.
3. Close at least one external Cn(alpha) / CP / stability benchmark before claiming predictive static stability.
4. Keep 6-DOF trajectory replay and RASAero comparisons as supporting evidence, not primary proof.
